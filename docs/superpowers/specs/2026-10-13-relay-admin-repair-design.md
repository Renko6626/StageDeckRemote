## 行为

1. Relay 即使没有 MJPEG 观看者也保留最新帧；导播推流初连/重连立即发送已有帧。
2. 同一 session 的新控制连接接管后，旧连接不能更新 token、心跳或响应请求；旧连接退出不能清掉新连接的 pending。
3. 同一 session 的最新推流连接负责画面及连接状态，旧连接退出不把新连接标为离线。
4. presenter 路由只接受既有格式 `[A-Z0-9-]{4,16}` 的 sid，拒绝 HTML 注入。
5. Relay 设置继续重启生效。保存只改变磁盘待生效配置，运行状态和二维码仍指向正在使用的配置。校验地址/密钥并把保存失败返回 GUI。
6. admin 保持只读和 5 秒刷新。中文字段及连接文字、移动端可阅读布局；说明静止 PPT 不产生新帧，避免把 LAST FRAME 当断线依据。
