# 本地诊断日志

用户已确认：保留导播简洁日志，增加本地详细日志文件、打开目录入口、详细诊断开关及手机错误回传。不增加云端服务、依赖或 SSE，不改变控制权限与执行语义。

日志目录使用 Tauri app_log_dir。JSONL 每条含时间、级别、模块、消息；每文件最多 5 MiB，保留当前文件及 3 份历史。常规事件持续持久化，详细模式仅本次进程有效，记录成功请求和 COM 步骤。目录或写入失败显示在日志面板，不阻断业务，不自动恢复或重试。

共享 Diagnostics 负责文件、轮换、模式和写入错误；log.rs 保留内存事件并增加仅文件的诊断接口。COM 工作线程使用作用域上下文记录调用步骤，包含调用前记录，以定位不返回的调用。HTTP 日志只记录路径，不记录 query/body/凭据。手机错误回传沿用 token 验证及 Relay HTTP 隧道，单次尽力发送，频繁同类错误抑制，不自动重试。文本过滤当前访问码、Relay 密钥、URL 查询凭据；不记录正文、图像或 COM 返回值。

手机反馈区分未执行、执行失败和超时结果未知。详细模式不记录每帧画面，捕获异常和生命周期记录到文件。

验证使用现有 Vitest/Rust 框架，补充文件轮换/过滤、错误上报验证和模式切换等关键覆盖。运行前端检查、相关 Rust 测试和 Windows 交叉编译；不自动运行浏览器交互，不生成安装包。
